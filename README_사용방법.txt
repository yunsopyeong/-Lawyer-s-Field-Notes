[프로그램 목적]
결산보고서 PDF(재무상태표/손익계산서)에서 계정과목과 금액을 읽어 엑셀 템플릿에 자동 입력합니다.

[폴더 준비]
1) INPUT/PDF 폴더에 PDF 파일을 넣습니다.
2) INPUT/template.xlsx 파일을 준비합니다.

[최초 1회]
1) INSTALL_REQUIREMENTS.bat 더블클릭

[실행]
1) RUN_EXCEL_AUTOFILL.bat 더블클릭
2) 결과는 OUTPUT/RESULT_날짜시간 폴더에 저장됩니다.

[생성 파일]
- parsed_financials.json
- parsed_financials.csv
- autofilled.xlsx
- 확인필요_미매칭항목.txt
- 오류검사결과.txt
